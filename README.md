### 🩸 Blood Drop — Blood Donation Management System (MERN)
🔗 **Live Site:** https://blood-drop-b7711.web.app  
🔗 **Client Repository:** https://github.com/zubairz40-z/Blood-Donation-Client.git  

![Blood Drop Screenshot](https://github.com/zubairz40-z/zubairz40-z/blob/main/Screenshot%202025-12-31%20185012.png?raw=true)

**Project Overview**  
A role-based blood donation platform designed to efficiently manage donors, requests, and funding.

**Core Features**
- Firebase Authentication & JWT security  
- Admin, Donor & Volunteer dashboards  
- Search donors by blood group & location  
- Donation request lifecycle management  
- Funding system with analytics  

**Technologies Used**
- React, Vite, Tailwind CSS, DaisyUI  
- Node.js, Express.js, MongoDB  
- Firebase Authentication, JWT  

**How to Run Locally**
1. Clone the repository  
2. Install dependencies: `npm install`  
3. Add environment variables  
4. Run the app: `npm run dev`
