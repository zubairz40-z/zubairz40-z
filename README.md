### 🩸 Blood Drop — Blood Donation Management System (MERN)

🔗 **Live Site:** [https://blood-drop-b7711.web.app](https://blood-drop-b7711.web.app)
🔗 **Client Repository:** [https://github.com/zubairz40-z/Blood-Donation-Client.git](https://github.com/zubairz40-z/Blood-Donation-Client.git)

![Blood Drop Screenshot](https://github.com/zubairz40-z/zubairz40-z/blob/main/Screenshot%202025-12-31%20185012.png?raw=true)

**Project Overview**
A role-based blood donation platform designed to efficiently manage donors, requests, and funding.

**Core Features**

* Firebase Authentication & JWT security
* Admin, Donor & Volunteer dashboards
* Search donors by blood group & location
* Donation request lifecycle management
* Funding system with analytics

**Technologies Used**

* React, Vite, Tailwind CSS, DaisyUI
* Node.js, Express.js, MongoDB
* Firebase Authentication, JWT

**How to Run Locally**

1. Clone the repository
2. Install dependencies: `npm install`
3. Add environment variables
4. Run the app: `npm run dev`

### 🚲 Zeutex — E-Bike Platform

🔗 **Live Site:** [https://zeutex-bike-shop.vercel.app](https://zeutex-bike-shop.vercel.app)
🔗 **Repository:** [https://github.com/zubairz40-z/Zeutex-Bike-Shop.git](https://github.com/zubairz40-z/Zeutex-Bike-Shop.git)

![Zeutex Screenshot](https://github.com/zubairz40-z/zubairz40-z/blob/main/Screenshot%202026-01-30%20191811.png)

**Project Overview**
A modern, responsive web platform for electric bikes. Users can explore models, view specifications, schedule test rides, and submit trade requests for old bikes.

**Core Features**

* Explore bikes with animated cards and interactive sliders
* Detailed bike pages with specs (speed, range, battery, motor)
* Login authentication with Email & Google
* Protected routes for adding bikes
* Trade requests for old bikes with images and notes
* Toast notifications for success/error messages
* Responsive UI with Framer Motion animations

**Technologies Used**

* Next.js, React, Tailwind CSS
* Firebase Authentication
* JSON-based product data
* Framer Motion & Swiper.js for animations

**How to Run Locally**

1. Clone the repository
2. Install dependencies: `npm install`
3. Add Firebase environment variables
4. Run the app: `npm run dev`
